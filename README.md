# Final Project: Web and Internet Fundamentals

This vanilla project includes a **cheatsheet** for **HTML**, **CSS**, and **JavaScript**, and a simple **profile page**.

## Features
- Simple profile page demonstrating basic structure and styling
- Cheatsheet covering essential **HTML**, **CSS**, and **JavaScript** syntax
- Responsive layout using CSS
- Lightweight and easy to understand

## How to See It
1. Download or Clone this repository.
2. Open the `index.html` file in Visual Studio Code.
3. Use Live Server extension in VS Code to see the project in your browser.
